# Day 01 · Task 1: Install Python 3.12, VS Code and Git

> Download Python from python.org and tick 'Add python.exe to PATH' on Windows. Install VS Code plus the Python extension. Install Git from git-scm.com. Check in a terminal: python --version and git --version.

## Checklist
- [x] Python 3.12 installed. Output of `python --version`: 3.11.9
- [x] VS Code + Python extension installed
- [x] Git installed. Output of `git --version`: 2.41.9.windows.3
- [x] Set your git identity:
  ```
  git config --global user.name "Your Name"
  git config --global user.email "you@example.com"
  ```
