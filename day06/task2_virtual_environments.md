# Day 06 · Task 2: Virtual environments

> python -m venv .venv, activate it, pip install requests, pip freeze > requirements.txt.

## Commands
```
python -m venv .venv
# Windows:      .venv\Scripts\activate
# Mac/Linux:    source .venv/bin/activate
pip install requests
pip freeze > requirements.txt
```
- [ ] Your terminal prompt shows `(.venv)`
- [ ] `requirements.txt` contains `requests`

Why use a virtual environment instead of installing everything globally?
