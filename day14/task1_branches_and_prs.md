# Day 14 · Task 1: Branches and PRs

> git checkout -b feature/news, commit, push, open a PR on GitHub, merge it.

## Do this once
```
git checkout -b feature/news-cli
# ...make changes...
git add .
git commit -m "Add news CLI"
git push -u origin feature/news-cli
```
- [ ] Opened a Pull Request on GitHub
- [ ] Merged it
- [ ] `git checkout main && git pull` shows the change
